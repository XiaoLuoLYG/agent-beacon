# Changelog

## v0.1.0

Initial private preview release.

- Adds the Agent Beacon macOS menu bar app.
- Shows aggregate counts for completed, needs-review, failed, and running tasks.
- Expands into a compact task list on hover.
- Connects supported CLI-launched agents through local shims.
- Reads Codex local session metadata and Cursor composer header metadata.
- Includes `AgentBeaconStatus` for direct status updates.
- Includes `agent-beacon-run` for wrapping existing commands.
- Packages the app, CLI helpers, screenshots, README, and quickstart guide into `AgentBeacon-macOS.zip`.
